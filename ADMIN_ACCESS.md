## Cara Akses Panel Admin

### Metode 1: Keyboard Shortcut
- Tekan `Ctrl + Shift + A` bersamaan di halaman website
- Akan langsung diarahkan ke halaman login admin

### Metode 2: Triple Click Logo
- Klik logo TRPL 3x dengan cepat sambil menekan `Ctrl`
- Logo akan mendeteksi triple click + Ctrl dan redirect ke admin

### Metode 3: URL Tersembunyi
Akses langsung melalui URL:
- `http://localhost:5174/#/trpl-system-management`
- `http://localhost:5174/#/dashboard-admin-secret`

### Metode 4: Console Command
- Buka Developer Tools (F12)
- Ketik di console: `adminAccess()`
- Tekan Enter
